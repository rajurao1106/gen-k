# Gen-K

Gen-K is a Next.js App Router application with server-rendered SEO landing
content and an interactive astrology experience. It includes online kundali,
kundali milan, numerology, mahadasha and AI Friend tools.

## Requirements and local development

- Node.js 20.9 or newer
- npm

Install dependencies and run the frontend and Express API together:

```powershell
npm install
npm run dev
```

Next.js runs at `http://localhost:3000`; the Express API runs at
`http://localhost:5000`. `npm run build` creates a production Next.js build,
and `npm start` serves that build.

## Deployment and SEO

Import the repository into Vercel and keep the project framework set to
**Next.js**. Vercel builds the App Router pages and routes `/api/*` requests to
the existing Express serverless handler.

Set `NEXT_PUBLIC_SITE_URL` in Vercel to the production site's canonical origin
(for example, `https://your-domain.com`, without a trailing slash). If omitted,
the app uses Vercel's production deployment URL when available. Page titles,
descriptions, Open Graph metadata, canonical URLs, `sitemap.xml` and
`robots.txt` are generated by the Next.js app.

The public interactive pages are:

- `/`
- `/kundali`
- `/milan`
- `/numerology`
- `/mahadasha`
- `/ai-friend`

The admin pages `/login` and `/user-data` are marked `noindex`.

## Environment variables

Configure server-only API keys and database credentials in the Vercel project
environment; do not add them to source control. Gemini accepts
`GEMINI_API_KEYS` or the numbered `GEMINI_API_KEY` variables.

Frontend settings use the `NEXT_PUBLIC_` prefix:

- `NEXT_PUBLIC_SITE_URL`: canonical production origin; recommended for SEO.
- `NEXT_PUBLIC_API_URL`: optional API origin. Leave unset on Vercel to use the
  same-origin `/api` serverless function. Local development defaults to port
  `5000`.
- `NEXT_PUBLIC_CHATTERBOX_URL`: optional voice-service URL; defaults to
  `http://127.0.0.1:8001`.
- `NEXT_PUBLIC_ADMIN_PASSWORD`: compatibility setting for the existing
  client-side admin login. Values exposed with this prefix are visible in
  browser code and must not be treated as a secure server-side credential.

When migrating an existing `.env`, rename any `VITE_API_URL`,
`VITE_CHATTERBOX_URL` and `VITE_ADMIN_PASSWORD` settings to their corresponding
`NEXT_PUBLIC_` names. Keep Gemini keys server-only.

## AI Friend and local voice replies

AI Friend chat uses the configured Gemini API key. Voice samples are saved
per Kundli profile in the browser's IndexedDB. Spoken replies use the local
Chatterbox Multilingual V3 service; the service listens only on `127.0.0.1`,
and the selected profile's reference sample is sent to that local process for
each generated reply. The model weights are downloaded on first startup.

Chatterbox supports Hindi and English voice cloning. See the
[Chatterbox project](https://github.com/resemble-ai/chatterbox) and its
[MIT license](https://github.com/resemble-ai/chatterbox/blob/main/LICENSE).
Browser microphone transcription uses the browser's Speech Recognition API;
the browser may use its own online speech service.

On Windows, use Python 3.13 and start the voice service in a separate terminal:

```powershell
py -3.13 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-chatterbox.txt
python server\chatterbox_service.py
```

Leave that terminal running, then start the web app with `npm run dev`. The
voice model can require substantial disk space and compute; the service uses a
CUDA GPU when PyTorch detects one, otherwise it runs on CPU and may be slow.
The chat can still return text when the local voice service is stopped.
